# LLM 能否協助排程實驗與錯誤分析？

**狀態：待驗證。** 如何評估大型語言模型能否協助把製程規則轉成可檢查的限制，或解釋排程中由機台與 AGV 形成的瓶頸？

目前可用的排程基線為 [Liu 等人（2023）](../sources/liu-2023-ipps-agv.md)第 3–5 節及其[關鍵路徑方法](../concepts/critical-path-search-in-ipps.md)。

下一步可用同一批案例比較人工與 LLM 輔助產出的限制描述，再由獨立驗證器檢查工序優先關係、資源衝突與搬運時間。分別記錄錯誤率、人工修正時間與可行排程的 makespan，並保留模型版本與提示。
