# LLM 研究 Wiki

這是依 Andrej Karpathy 的 LLM Wiki 構想建立的繁體中文研究知識庫。原始資料放在 `raw/`，代理整理與交叉連結的內容放在 `wiki/`，維護規則見 [AGENTS.md](AGENTS.md)。

1. 把第一篇 PDF 放入 `raw/papers/`。網路文章放在 `raw/articles/`，技術報告放在 `raw/reports/`，附圖和附件放在 `raw/assets/`。
2. 在專案根目錄請 Codex 執行「依照 AGENTS.md，收錄 raw/papers 裡的這篇論文，並整理它的主要發現與實驗限制」。
3. 從 [索引](wiki/index.md) 瀏覽知識頁，從 [日誌](wiki/log.md) 查看更新紀錄。也可在 Obsidian 將解壓後的根目錄開啟為 vault。

目前收錄一篇 AGV 排程研究，可由索引查閱。作業展示頁在 [site/index.html](site/index.html)，完整繳交說明在 [SUBMISSION.md](SUBMISSION.md)。[Karpathy 原始構想](https://gist.github.com/karpathy?direction=desc&sort=updated)
